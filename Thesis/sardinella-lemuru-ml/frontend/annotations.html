About the JSON format

The dataset object describes the format and export time. Each image includes its identifier, dimensions, file name, categories, metadata, and saved annotations. Each annotation retains its class ID/name, bounding box in [x, y, width, height] pixels, COCO polygons or RLE mask, fish/object IDs, confidence, source, review state, and creation/modification timestamps. Class registry IDs and original source metadata are retained. Unreviewed archival exports require review before training.
