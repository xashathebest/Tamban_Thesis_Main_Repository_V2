# Prompt 03 — Reliable direct Google Drive sync

Execute only after the owner supplies the destination link(s) and approves an appropriate authentication approach. Never pretend a Drive URL grants write access. Capture works offline without a link or credentials.

Use the SAME durable order for both manual `Capture Photo` and automatic timer shots: atomic local frame save -> SHA-256 and capture metadata (including manual/automatic mode) -> durable sync queue -> Google Drive upload -> save returned file ID/verification/status. Do not create different upload paths for different capture modes. Prefer opt-in auto-sync; add connection test, sync now, pause/retry failed, progress and open Drive folder. Display **Saved locally / Queued / Uploading / Synced to Drive / Failed** separately; never label queued files synced. Keep a persistent local-to-remote mapping and idempotency keys to prevent duplicate retries after crashes. Bounded retry with exponential backoff for network/429/5xx; 401/403 require intervention. Don't overwrite remote originals, don't delete unsynced photos, never silently overwrite two identical names.

Choose either OAuth2 installed-app consent for user-owned My Drive or an explicitly permitted service-account/shared-folder approach. Confirm actual folder capability before implementing; if new library dependency is genuinely necessary, propose exact minimal package(s) and obtain permission. Store credentials server-side securely; no private key in source, prompts, logs, JS, localStorage or Git. Restrict all mutating endpoints to existing LAN operator roles, CSRF/same-origin where applicable. Validate folder IDs, allowlist root destination, prevent path traversal. Support shared drives if applicable and approved.

Suggested per-session Drive tree: selected authorized destination / date / session_id / raw / images, plus manifest CSV/JSON. Preserve filenames, timestamps, checksums and source session IDs. Test with fake Drive client, not live accounts in CI. Report real cloud tests separately after authorization.
