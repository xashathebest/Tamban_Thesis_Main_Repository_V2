# 09 — Input handling, recovery and LAN exposure

`src/api/app.py` bounds upload bytes while reading, including absent or misleading content length; `src/api/image_analysis.py` checks image format and dimensions before pixel decoding. Camera and Model 2 failures report errors or Ungraded results and retry without reusing stale grades. Session tests exercise failed creation, stalled stops and recovery. The preceding phase also fixed formula-like operator text in CSV/XLSX.

The default local deployment is intended for loopback use. A non-loopback bind through `src/api/__main__.py` requires enabled role-based LAN authentication and TLS certificates. LAN middleware restricts unauthorized reads and writes, applies CSRF protection to browser mutations, and disables remote debug by default. Use one API worker for one camera. Shared tokens are not individual identity, and a proxy that conceals client addresses changes trust assumptions; see README deployment notes. These tests do not certify a real network deployment, firewall, trusted certificate, proxy or institutional authorization.

No new production code was required by this phase. Physical camera, GPU and actual remote-network recovery remain untested.
