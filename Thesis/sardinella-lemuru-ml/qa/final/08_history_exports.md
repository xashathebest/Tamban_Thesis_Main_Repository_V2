# 08 — Historical review and export fidelity

Inspected `src/api/database.py`, history/review/export routes in `src/api/app.py`, `src/api/export.py`, and the export/history UI. Review identity is session-qualified, original AI results are retained, and manual changes have a separate audit trail. Exports use recorded historical policy; multi-session Excel includes session configurations and row mappings. The interface honors selected columns; full evidence is an explicit choice. Existing tests cover duplicate track IDs across sessions, review/undo, unknown sessions, policy immutability, historical configuration, time-zone filtering and pagination.

One issue was reproduced: operator-provided text beginning with `=` was written into CSV in a form spreadsheet software could execute; XLSX similarly inferred formulas from strings. The pre-fix test output is `08_export_reproduction.log` (1 failed, 1 passed). `src/api/export.py` now prefixes formula-like CSV text with an apostrophe and forces XLSX formula-looking strings to literal cell text across sheets. `tests/test_export_selection_qa.py` covers the reproducer, whitespace/control/formula prefixes, ordinary quoted/newline Unicode text, timestamps, and empty export headers. This changes representation of formula-like CSV text, not stored inspection data; `README.md` documents it. No schema migration or historical data rewrite was needed.

Focused command: `python -B -m pytest -q -p no:cacheprovider tests/test_historical_review_qa.py tests/test_historical_export_qa.py tests/test_export_selection_qa.py tests/test_history_performance_qa.py tests/test_tail_optional_policy.py --tb=short`: **45 passed, 12 subtests, 1 warning** (`08_history_exports.log`). `tests/historical_review_smoke.py` and `tests/export_form_smoke.py` passed in headless Chrome on temporary local servers (`08_browser_history.log`, `08_browser_export.log`). Synthetic sample artifacts: `08_synthetic_export.csv` and `08_synthetic_export.xlsx`; they contain no real inspection records.
