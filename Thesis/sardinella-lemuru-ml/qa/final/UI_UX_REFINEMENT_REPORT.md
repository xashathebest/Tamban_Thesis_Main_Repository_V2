# UI and UX refinement report

Live feed mode and AI processing rate are explicitly identified; actual preview FPS and display latency are not measured. Desktop uses sidebar Settings/Export and mobile uses header equivalents. Analytics opens its Live disclosure, and feed display options remain next to the feed. The stopping state disables repeated Stop and errors display the backend message. Export validates selection and reports failures in its own dialog.

Headless keyboard and layout checks cover 390×844, 1280×900, 1366×768 and 1920×1080; screenshots and limitations are in `16_responsive.md`. Physical devices, screen readers, zoom, contrast and real overlay alignment remain unvalidated.
